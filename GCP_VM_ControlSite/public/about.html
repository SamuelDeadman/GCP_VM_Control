About This Project

This sit exists to act as a test bed for the ability for me to create a admin console to allow for zero trust control over a VM machine running in GCP to allow a person to control and see server status, along with contains remote connection info in case of any IP changes.

Goals

  • Create a high end VM mahsine that run an ARMA 3 gaming server reliably
  • Automation of server up and down time while still allowing high random availablity with scale to zero to reduce costs.
  • Node JS hosted Website in GCP to allow for zero trust control of the VM mashine, and feedback for them to see the server status.
  • Doucment this process of development in this site.

Technologies Used

  • GCP
  • HTML / CSS / JavaScript
  • Node JS
  • Cloud Run
  • Compute Engine, Instance templates, Instance groups
  • Pub/Sub
