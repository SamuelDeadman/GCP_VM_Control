# GCP_VM_Control
Application to allow for the stop, start and suspedning of a GCP Compute Engine hosting a gaming communitys servers. Allowing for saving in costs compared to a dedicated server box. Website where a user logs in using a google acount on an accept list to allow for the stopping and starting on the server without the user needing to ever lean the GCP.
